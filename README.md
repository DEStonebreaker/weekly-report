# Weekly Report  
Weekly report is a small program that I developed to interact with [Google Tasks](https://workspace.google.com/products/tasks/) and send an email, reporting upcoming tasks for a given task-list.  

When running this for the first time, you will be ask to authorize weekly-report/tasks access to send emails on your behalf and read-only access to Google Tasks. We cannot view your personal emails or destroy any of your tasks.
